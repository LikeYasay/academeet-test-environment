AcadeMeet — Quick Overview

A short guide for SQA engineers: sample data, common passwords, and feature triggers.

Sample Data
Seeded sessions & notifications are available via Settings → Quick Test Actions.
  • Trending sessions: small set of seeded sessions for acceptance tests.
  • Notifications: generated when you join sessions or when reminders are scheduled.
Notifications / Reminders
Notifications are triggered:
  1. When a user is invited or a session they're part of is updated.
  2. Scheduled reminders (24h and 1h) are created when a session is saved.
  3. Use "Seed Test Notifications" in Settings to create test notifications.
SQA Guidance
  • Toggle "Simulate Notification Load Error" to test error states for notifications.
  • Use "Simulate Network Error" before creating a session to test save-failure UX.
  • Verify reminders do not duplicate — the app deduplicates by reminder key.
Out of scope (for tests)
The app uses localStorage-only persistence; no backend integration is included. External calendar sync and real email notifications are out of scope and only simulated.
